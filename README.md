## 실습 요약

가상 지출 28건을 사용했습니다. 10월 기록은 24건, 합계는 195,700원입니다. 별도 Linux 환경의 MySQL 8.0.46에서 SQL을 실행하여 날짜 조건·합계·정렬·수정 후 원본 유지 등 11개 점검을 통과했습니다. 사용자의 컴퓨터에서는 제공 SQL로 다시 실행해 보세요.

OT 문서는 직접 확인했습니다. 교수 제공 영상은 접근 제한으로 직접 시청하지 못하여, 사용자의 동의에 따라 제목·링크를 추가 학습 자료로 구분했습니다. 특정 영상 설명이나 시간대를 인용하지 않았습니다.
